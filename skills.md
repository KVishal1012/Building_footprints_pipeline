# Project Skills

This repository is set up for geospatial data engineering work around US structure datasets.

## Current Capabilities

- Build city-level structure polygon layers.
- Merge Overture and Microsoft building footprints.
- Attach OpenStreetMap building tags.
- Attach National Structure Inventory point attributes.
- Estimate residential units, stories, and occupant counts.
- Attach parcel attributes from local files or supported ArcGIS REST sources.
- Export GeoParquet outputs for GIS, analytics, and downstream enrichment.

## Useful Python Skills

- GeoPandas and Shapely for geometry operations.
- PyArrow and GeoParquet for efficient columnar storage.
- OSMnx for OpenStreetMap extraction.
- Mercantile for tile-based Microsoft footprint downloads.
- Pandas and NumPy for attribute normalization.
